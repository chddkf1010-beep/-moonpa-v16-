# 문파 키우기 초상화 자산 관리

## 기본 시드 16: 고유 얼굴 20명

- **배포됨:** `founders/founder_atlas.webp` — 20명 초상화가 5열 × 4행으로 들어간 경량 아틀라스 (48px/인물).
- **연동됨:** `engine/moonpa_portraits.py`에서 창설 문파원의 **fid + 이름 + 역할**을 검증해 초상화를 지정합니다.
- **영입/이적:** 고유 초상화 키는 문파가 아니라 `Fighter.portrait_key`에 남으므로 이적 후에도 유지됩니다.
- **게임 화면:** 고유 WebP 파일이 있으면 우선 노출합니다. 파일이 없으면 고유 아틀라스, 아틀라스도 없으면 역할별 그림/이니셜을 표시합니다.
- **고해상도 20장:** `assets/portraits/founders/seed16_640.webp`부터 `seed16_659.webp`까지의 원본에 가까운 파일은 채팅에서 전달한 `moonpa_founder_20_portraits_seed16.zip`에 있습니다. **개별 원본 파일 20장은 GitHub에 아직 업로드하지 않았습니다.**
- `founder_manifest.json`은 이름·역할·ID·이미지 경로를 기록합니다.

## 역할별 기본 초상화

아래 여섯 파일은 개별 그림이 없는 다른 시드의 문파원·AI 문파원에게 사용하는 역할 기반 초상화입니다. 이 파일도 **GitHub에 아직 업로드되지 않았습니다**. 채팅에서 전달한 ZIP에 포함되어 있습니다.

| 역할 | 필요 파일 |
|---|---|
| 수호형 | `guardian_card.webp` |
| 무인형 | `warrior_card.webp` |
| 사수형 | `archer_card.webp` |
| 주술형 | `shaman_card.webp` |
| 치유형 | `healer_card.webp` |
| 암살형 | `assassin_card.webp` |

## 확장 원칙

현재 **기본 시드 16만** 20개 개별 초상화가 매핑되어 있습니다. 다른 시드의 창설 멤버에게는 의도적으로 다른 사람 얼굴을 배정하지 않습니다. 향후에는 생성 시점에 `portrait_key`를 지정하고, 이름·소속과 독립적으로 저장하도록 확장해야 합니다.

이미지는 캐릭터 데이터가 가진 ID로 접근하며, 소속 문파 이름이나 순위는 이미지 키에 포함하지 않습니다.
