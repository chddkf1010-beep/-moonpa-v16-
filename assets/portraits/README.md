# 역할별 초상화

수호·무인·사수·주술·치유·암살의 공용 카드 초상화 6종을 사용한다. 명부와 전투 화면에서 역할에 맞는 초상화를 표시한다.


## 초기 문파원 20명: 이름별 고유 초상화
- 기본 시드 16에서 생성되는 초기 문파원 20명(ID 640~659)은 소속 문파가 아닌 `Fighter.portrait_key`에 고유 얼굴을 저장한다.
- **실제 배포:** `founders/founder_atlas.webp` (5열×4행, 기본 카드용 경량 이미지)과 `founder_manifest.json`.
- 명단·주간 운영·전투 모두 개별 WebP → 고유 얼굴 아틀라스 → 역할 초상화로 표시한다.
- 이적 후에도 이름/ID/초상화 정보는 그대로 유지한다.
- 다른 시드는 같은 이름이나 ID가 우연히 일치해도 다른 인물의 얼굴을 잘못 적용하지 않는다.
- 고품질 개별 파일 20장은 채팅 산출물 `moonpa_founder_20_portraits_seed16.zip`에 포함되어 있으며, **아직 저장소에 업로드되지 않았다.** 업로드 시 아틀라스보다 우선 표시된다.


## 외형 다양성 v1 — 신규 초상화 16종

- `diverse/atlas_v1.webp`는 **직접 제작한 신규 무협 인물 초상화 16명**을 4×4로 담은 224×224 WebP 아틀라스다. 기존 직군 공용 그림 6장과 기본 시드 16의 창설 문파원 20인 고유 얼굴은 삭제하거나 교체하지 않는다.
- 등장 인물은 장년·노년풍 얼굴, 통통한 얼굴, 푸근한 인상, 흉터, 수염, 거친 외형, 날카로운 눈매 등을 포함한다. **외형은 성능, 성향, 선악, 희귀도를 결정하지 않는다.**
- `engine/moonpa_portraits.py`의 `DIVERSE_PORTRAITS`가 각 칸의 직군·최소 연령·인상·세부 특징을 정의한다. 캐릭터가 새로 태어날 때 `portrait_key=diverse/v1_00.webp` 등 **논리적인 타일 키**를 저장한다. 물리 파일 16장이 있는 것이 아니라 `game.js`의 `portrait()`가 아틀라스 칸으로 치환한다. 다른 UI에서 이 키를 그대로 `<img src>`로 사용하지 않는다.
- `assign_diverse_portrait(seed,fighter)`는 고유 인물 ID, 세계 시드, 역할과 등장 시점 나이로 후보를 고르고 **세계·경제 난수 상태를 소모하지 않는다**. 직군/나이에 맞는 타일이 없으면 기존 직군 카드 그림으로 표시한다.
- 생성 당시의 초상화 정보는 이미 존재하던 `Fighter.portrait_key`에 저장된다. 이름, 문파, 직군, 나이, 이적, 방출, 계약, 세이브/로드, 전설 각성과 무관하게 **얼굴은 고정**된다.
- 기본 시드 16에서 창설 문파원 20명은 `assign_default_founder_portrait`가 원래 고유 얼굴을 최종 우선 적용한다. 다른 시드는 창설 문파원도 다양성 아틀라스 후보가 된다.
- **구버전 저장 파일**은 기존 `portrait_key`가 비어 있어도 강제로 변경하거나 재배정하지 않는다. 이후 생성되는 신규 신인에게만 새 규칙을 적용한다.
- 명부, 인물 상세, 낭인 시장, 스카우트, 문파 간 소속 목록, 전투 편성에서 같은 얼굴을 사용한다. 독립 8대8 연무장 전투 로직과 애니메이션 파일은 수정하지 않는다.

### 테스트

```bash
PYTHONPATH=engine python -m unittest discover -s tests -v
node --check game.js
node --check management.js
```

특히 `tests/test_portrait_diversity.py`는 아틀라스의 실제 존재, 직군·나이 제한, 결정론, 구버전 얼굴 보존, 초기 고유 얼굴 우선순위, 저장/불러오기 및 외형과 능력치 독립성을 검증한다.
